# クイックスタート（日本語）

このUSBメモリだけで動作する、完全オフラインの医療文書作成支援ツールです。
インストール不要・管理者権限不要・インターネット接続は一切使用しません。

> **重要**: 本ツールは下書き作成の支援ツールであり、臨床的検証は行われていません。
> すべての出力は、カルテに記載する前に**必ず医師が確認・修正**してください。
> 詳細は [LICENSES/DISCLAIMER.md](LICENSES/DISCLAIMER.md) を参照してください。

## 手順 1 — 起動する

- **Windows**: エクスプローラーでUSBドライブを開き、`START_WINDOWS.bat` をダブルクリックします。
  - 青い画面で「**WindowsによってPCが保護されました**」(SmartScreen) と表示された場合は、
    **詳細情報 → 実行** をクリックしてください。リムーバブルメディア上の未署名スクリプト
    では正常な表示です。初回は [WINDOWS_VALIDATION_CHECKLIST.md](WINDOWS_VALIDATION_CHECKLIST.md)
    に従ってください。
- **macOS**（Apple Silicon）: FinderでUSBドライブを開き、`START_MAC.command` をダブルクリックします。
  - 「開発元が未確認のため開けません」と表示された場合は、
    **ファイルを右クリック（Controlキー+クリック）→ 開く → 開く** を選択してください。

黒いコンソール画面が開き、モデルを読み込みます（初回は1〜2分かかることがあります）。
その後、ブラウザが自動的に `http://127.0.0.1:8180/` のようなアドレスで開きます。
このアドレスは**このPCの内部だけ**で完結しており、外部には何も送信されません。

## 手順 2 — 文書の下書きを作成する

1. ブラウザ画面の左側から文書プリセットを選択します:
   - 退院サマリー
   - 手術記録
   - 看護記録（SOAP）
   - 診療情報提供書
   - 匿名化支援（マスキング）
2. 短い入力フォームに記入するか、診療メモを貼り付けます。
3. 生成ボタンを押して、下書きの完成を待ちます。

患者氏名・患者ID・住所・電話番号は**入力しないでください**。
プリセットは年齢・性別と臨床情報のみで動作するように設計されています。

## 手順 3 — 確認・転記・終了する

1. **下書き全体を必ず読み**、誤りと `【要確認】` の箇所をすべて修正してください。
   文書の責任者は医師本人です。
2. 修正済みの本文を、手作業で電子カルテ等に転記してください。
3. 終了時: ブラウザのタブを閉じ、`STOP_WINDOWS.bat`（Windows）または
   `STOP_MAC.command`（macOS）を実行し、コンソール画面が閉じたのを確認してから
   「ハードウェアの安全な取り外し」（macOSでは取り出し操作）を行ってください。
4. USBメモリを返却し、持ち出し管理台帳に返却記録を記入してください
   （[CUSTODY_REGISTER_TEMPLATE.md](CUSTODY_REGISTER_TEMPLATE.md)）。

## うまく動かないとき

- 何も起きない／画面がすぐ閉じる: 別のUSBポートで再試行してください。
  ファイルをUSBの外にコピーせず、必ずUSB直下から起動してください。
- ブラウザが開かない: 手動でブラウザを開き `http://127.0.0.1:8180/` に
  アクセスしてください（使用中の場合は 8181〜8199 を試す）。
- 非常に遅い: PCのメモリが8GB未満の可能性があります。別のPCをご利用ください。
- 新しいWindows PCで初めて使う場合: 情報システム部門の立ち会いのもと、
  [WINDOWS_VALIDATION_CHECKLIST.md](WINDOWS_VALIDATION_CHECKLIST.md) を一度実施してください。
