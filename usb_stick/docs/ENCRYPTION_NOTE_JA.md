# 暗号化に関する注意（日本語）

本USBパッケージの保護方法と、一般的なソフトウェア方式を採用しなかった理由。

## 推奨: ハードウェア暗号化（PINキーパッド付き）USBドライブ

本パッケージは、**本体に物理PINキーパッドを備えたハードウェア暗号化ドライブ**に
搭載して運用してください。例:

- **Kingston IronKey Vault Privacy 80ES**（FIPS 197、XTS-AES 256、タッチスクリーンPIN）
- **Apricorn Aegis Secure Key / Aegis Padlock** シリーズ（FIPS 140-2/140-3 認証、本体キーパッド）

この方式が病院の制約に適合する理由:

- 暗号化・復号は**ドライブ内蔵コントローラの内部**で行われます。正しいPINを
  ドライブ本体で入力した後にのみ、PCからは通常のUSBストレージとして見えます。
- ホストPC側に**ソフトウェア・ドライバ・管理者権限が一切不要**です。
  「インストール不要・管理者権限不要」という本パッケージの運用ルールと両立する
  唯一の暗号化方式です。
- OS非依存: WindowsでもmacOSでも同じ手順で解錠できます。
- PIN連続誤入力によるロックアウト／自動消去機能により、紛失時のデータを保護します。

## 不採用とした代替案（理由付き）

| 方式 | 判定 | 理由 |
| --- | --- | --- |
| **VeraCrypt**（ソフトウェア暗号化コンテナ） | **不採用** | ボリュームのマウントに VeraCrypt のカーネルドライバが必要で、その導入・読み込みには**管理者権限が必須**です（ポータブルモードでもドライバ読み込みに管理者権限が要ります）。病院PCでは許可されません。 |
| **BitLocker To Go** | **不採用** | Windows専用であり、**macOSでは解錠・読み取りできません**。本パッケージはWindowsとmacOSの両方で動作する必要があります。また、ホスト側のWindowsエディション・ポリシーに依存します。 |
| 暗号化なしの通常USBメモリ | 患者由来の文章を扱うスティックでは**不採用** | 紛失時に一切の保護がありません。臨床データを全く含まないデモ用のみ許容されます。 |

## ファイルシステム: exFAT を採用する理由

（ハードウェア暗号化ドライブの）データ領域は **exFAT** でフォーマットしてください。

- Windows 10/11 と macOS の両方で、追加ドライバなしに**読み書き**できます。
- **4GBを超えるファイル**に対応します（GGUFモデルは現在約1.9GBですが、
  将来のモデルは FAT32 の4GB上限を超える可能性があります）。
- NTFS は macOS では読み取り専用となり、監査ログの書き込みができないため回避します。

## 持ち出し管理台帳（必須）

すべてのスティックは**持ち出し管理台帳**で管理してください: 保管責任者、
持ち出し・返却の日時、使用目的を記録し、紛失（またはその疑い）は当日中に
報告します。同梱のテンプレートを使用してください:
[CUSTODY_REGISTER_TEMPLATE.md](CUSTODY_REGISTER_TEMPLATE.md)

スティック内の `audit/` フォルダには改ざん検知可能なハッシュチェーン形式の
利用ログが自動記録されますが、**物理的な**管理の記録（誰がいつ持ち出したか）は
デジタルログでは代替できないため、台帳が必要です。
